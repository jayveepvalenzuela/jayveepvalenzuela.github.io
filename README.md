# jayveepvalenzuela.github.io

My portfolio website built with Jekyll.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

## Getting Started

### Prerequisites
- [Ruby](https://www.ruby-lang.org/en/downloads/) (with Bundler: `gem install bundler`)

### Install & Run
```sh
bundle install
bundle exec jekyll serve
```
Site will be available at `http://localhost:4000`. See the [Jekyll docs](https://jekyllrb.com/docs/) for more.
